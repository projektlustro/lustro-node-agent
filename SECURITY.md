# Security Policy

## Scope

This policy covers the LUSTRO **node-agent** — the volunteer-run, sandboxed
classifier in this repository. You run it on your own machine to help classify
*public* work units. The private operator C2 surface is not distributed and is
out of scope.

## Reporting a vulnerability

Email **security@projektlustro.eu** with a description of the issue, the
affected component, and steps to reproduce. Do not open a public issue for a
vulnerability — email the contact above. This repository is public, so a public
vulnerability issue would broadcast it before a fix is available and put
volunteers at risk.

We aim to acknowledge reports promptly and will keep you updated as we work on
a fix.

## Disclosure

We follow a **90-day coordinated disclosure** window. We ask that you give us up
to 90 days to release a fix before any public disclosure, and we will
coordinate timing with you.

## Bounty

There is **no bug bounty program**. We are grateful for responsible disclosure
and will credit reporters who wish to be named.
